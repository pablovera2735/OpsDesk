# OpsDesk

Plataforma web para gestión de incidencias IT, inventario tecnológico,
usuarios, técnicos y SLA.

## Stack

### Frontend
- Angular
- TypeScript
- RxJS
- SCSS

### Backend
- Laravel
- PHP
- REST API
- Laravel Sanctum

### Database
- SQLite (development)
- PostgreSQL (production)

## Funcionalidades previstas

- Autenticación
- Gestión de usuarios y roles
- Gestión de incidencias
- Asignación de técnicos
- Inventario IT
- SLA
- Dashboard
- Auditoría
- Notificaciones
